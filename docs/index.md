# 📊 Sistema de Gestión de Facturas

Aplicación web profesional para administrar facturas con filtros avanzados y exportación de datos.

---

## 🚀 Comenzar Ahora

[**Abrir Aplicación Web →**](https://tu-usuario.github.io/contador-de-facturas/web/)

---

## ✨ Características

- 📝 **Fácil de usar** - Interfaz intuitiva y profesional
- 🔍 **Filtros avanzados** - Busca por cliente, monto, fecha, estado y proyecto
- 💾 **Almacenamiento local** - Tus datos están seguros en tu navegador
- 📊 **Exportación de datos** - Exporta a JSON
- 📱 **Responsive** - Funciona en desktop, tablet y móvil
- ⚡ **Sin dependencias** - Carga rápido, sin código externo

---

## 🎯 Características Principales

### Panel de Entrada
Agrega nuevas facturas con:
- ID único
- Fecha (DD/MM/YYYY)
- Nombre del cliente
- Monto
- Campos personalizables (proyecto, impuestos, estado)

### Panel de Filtros
Busca facturas por:
- 👤 **Cliente** - Búsqueda de texto
- 💰 **Monto** - Rango mínimo y máximo
- 📅 **Fecha** - Desde y hasta
- 🏷️ **Estado** - Pagada, Pendiente, Vencida
- 🎯 **Proyecto** - Búsqueda de texto

### Resultados en Tiempo Real
- 📋 Vista de todas las facturas
- 🔢 Totales automáticos
- ⏱️ Actualización instantánea

---

## 🛠️ Tecnología

- **Frontend**: HTML5, CSS3, JavaScript vanilla
- **Backend**: Python 3.7+
- **Almacenamiento**: localStorage del navegador
- **Exportación**: JSON, Excel (backend), PDF (backend)

## 💡 Casos de Uso

### 1. Gestor Personal
Si eres autónomo o freelancer, gestiona tus facturas fácilmente.

### 2. Control de Pagos
Separa facturas pagadas de pendientes y vencidas.

### 3. Análisis de Ventas
Filtra por cliente o proyecto para ver tus tendencias.

### 4. Reportes
Exporta datos a JSON para análisis en Excel o scripts.

## 🚀 Inicio Rápido

### 1. Abrir la Aplicación
[**Abrir en el navegador →**](https://tu-usuario.github.io/contador-de-facturas/web/)

### 2. Agregar una Factura
- Completa el formulario del lado izquierdo
- Haz clic en "Agregar Factura"

### 3. Filtrar Resultados
- Usa los filtros del lado derecho
- Haz clic en "Aplicar Filtros"

### 4. Exportar Datos
- Haz clic en "JSON" para descargar

¡Eso es todo! 🎉
