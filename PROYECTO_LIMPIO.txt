🚀 PASOS PARA GITHUB
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Instalar Git
  → Descargar desde https://git-scm.com

PASO 2: Configurar Git
  → git config --global user.name "Tu Nombre"
  → git config --global user.email "tu@email.com"

PASO 3: Crear repositorio en GitHub.com
  → New repository
  → Nombre: contador-de-facturas
  → Public: Sí
  → Copiar URL

PASO 4: Inicializar Git local
  → cd "c:\Users\kevin\OneDrive\Escritorio\Contador de facturas"
  → git init

PASO 5: Agregar archivos
  → git add .

PASO 6: Primer commit
  → git commit -m "Inicial: Sistema de Gestión de Facturas v1.3"

PASO 7: Conectar con GitHub
  → git remote add origin https://github.com/tuusuario/contador-de-facturas.git
  → Reemplaza "tuusuario" con tu usuario

PASO 8: Subir a GitHub
  → git branch -M main
  → git push -u origin main

PASO 9: Activar GitHub Pages
  → Settings → Pages
  → Branch: main
  → Folder: /docs
  → Save

PASO 10: Verificar
  → https://github.com/tuusuario/contador-de-facturas (repositorio)
  → https://tuusuario.github.io/contador-de-facturas (sitio web)
